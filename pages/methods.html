LEARNING METHODS

Методики

Не существует одной волшебной техники обучения. Здесь собраны конкретные методы для памяти, концентрации, понимания, планирования и подготовки к экзаменам.

Память

Active Recall

Вспоминание информации без подсказки вместо повторного перечитывания.

Память

Spaced Repetition

Повторение материала через увеличивающиеся интервалы времени.

Экзамены

Practice Testing

Проверка себя вопросами и задачами вместо пассивного чтения.

Понимание

Feynman Technique

Объяснение сложной идеи простыми словами, чтобы обнаружить пробелы в понимании.

Концентрация

Pomodoro

Работа короткими сфокусированными интервалами с запланированными перерывами.

Планирование

Time Blocking

Закрепление конкретного времени за конкретной задачей.

Концентрация

Single Tasking

Выполнение одной задачи за раз вместо постоянного переключения.

Понимание

Elaboration

Связывание нового материала с уже известными знаниями.

Понимание

Concept Mapping

Создание карты связей между понятиями, причинами и последствиями.

Ошибки

Error Log

Систематический разбор ошибок: причина → исправление → стратегия.

Экзамены

Mock Exam

Пробный экзамен в условиях, максимально похожих на настоящие.

Понимание

Self-Explanation

Проговаривание собственных рассуждений во время решения задачи.
